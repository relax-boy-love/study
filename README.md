# 前端求职学习记录

这个仓库用于记录我的前端基础复习、编程练习和错题总结。

我已经学习过 HTML、CSS、JavaScript 和 Vue 3，也跟随视频完成过简单的 Vue 3 后台管理项目。当前目标是通过持续练习补齐 JavaScript、TypeScript、Vue 和工程化基础，提高独立编码能力，为前端开发求职做准备。

## 学习安排

- 学习周期：12 周
- 每天时间：4 小时
- 每周学习：6 天
- 学习方式：理论学习、独立编码、错题整理、项目实践

## 如何查看

1. 克隆或下载仓库。
2. 使用浏览器打开每天目录中的 `.html` 文件。
3. 打开浏览器开发者工具，在 Console 中查看练习结果。
4. Markdown 文件用于记录学习过程、概念理解和错题订正。

## 学习原则

- 先预测结果，再运行代码验证。
- 先独立思考，再查看提示和答案。
- 不只记录正确代码，也记录错误原因。
- 每周进行一次闭卷复习和口述验收。
- 持续提交 Git 记录，展示学习和改进过程。
